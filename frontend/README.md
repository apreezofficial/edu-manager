Delightsome Kids — Frontend (Next.js App Router + TypeScript)

Quick start:

1. Install dependencies

```bash
cd frontend
npm install
```

2. Run development server

```bash
npm run dev
```

Frontend uses the App Router with routes under `/app`. Legal pages available under `/legal/terms`, `/legal/privacy`, `/legal/contact`.

Backend lives in `../backend` and can be started with PHP built-in server.
